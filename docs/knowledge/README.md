# 项目知识库

本目录保存项目长期有效的事实、约定和排障经验，是 AI 与开发者理解项目的稳定知识来源。

## 索引

- [项目概览](project-overview.md)：项目目标、技术栈、边界、命令和已确认的基础设施现状。
- [架构](architecture.md)：技术栈、组件职责和请求链路。
- [API 约定](api-conventions.md)：接口、校验和错误响应约定。
- [领域术语](domain-glossary.md)：项目领域术语和固定配置。
- [故障排查](troubleshooting.md)：常见启动、测试和调用问题。
- [仓库审计](repository-audit.md)：文档、工程、安全、可靠性和性能缺口审计。

## 维护

- 只记录已确认的项目事实，不记录未经验证的推测。
- 实现、配置或接口发生变化时，同步更新对应知识文档。
- 临时需求和实施过程放在 `docs/spec/`、`docs/plan/`、`docs/tasks/`，不要混入长期知识。
- 本目录文件使用稳定名称，不加日期前缀。
- 新增、删除或重命名知识文件时同步更新本索引和 `AGENTS.md`。
- 代码与 Knowledge 冲突时，将可验证代码作为当前事实并报告冲突，再同步文档；不得静默修改业务行为。
