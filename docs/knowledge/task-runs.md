# 长任务模式

长任务是普通聊天之外的可选模式，复用当前模型、会话和工具审批。模型回答“完成”不会直接完成任务；只有预设的确定性条件全部通过才会标记 `completed`。

Web 页面点击输入框旁的「任务」，填写目标和一项验收条件后创建并运行。可选「文件存在」「文件不存在」或固定项目检查；任务状态区显示结果，`needs_review` 时须先人工核对工作区，再点击「继续」。API 还支持多个条件和 SHA-256 验收，但首版页面只创建一个条件。

TUI 输入 `/task` 查看当前启动目录的任务；创建样例：`/task new 创建 answer.txt | file_exists:answer.txt`。也可使用 `file_absent:相对路径` 或 `project_check:compile`，其他固定检查名为 `test_all`、`pip_check`、`diff_check`。用 `/task resume 任务ID` 显式继续。

任务记录位于本机私有 `data/task-runs/`，公开状态响应和新增的任务状态日志不回显目标；模型请求日志仍可能按照现有设置记录输入内容，不要在任务目标中写入密钥。启动时遗留的执行中、等待审批和验收中任务会变为 `needs_review`，不会自动重放写操作或沿用旧审批。任务最多执行 3 轮；Web 每轮最多 10 分钟。TUI 的单轮时限仍由现有模型请求配置控制。Web 与 TUI 使用同一种记录格式，但任务绑定各自的项目/会话，不跨入口直接接管。
