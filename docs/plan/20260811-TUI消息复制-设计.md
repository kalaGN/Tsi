# TUI 消息复制设计

状态：已完成（2026-08-11）  
创建日期：2026-08-11

对应[需求](../spec/20260811-TUI消息复制-需求.md)。

## 1. Current Fact

Textual 8.2.8 的 App 和 Screen 默认允许任意文本选择，Screen 也已经绑定
`ctrl+c,super+c -> screen.copy_text`。但 `RichLog` 没有覆盖 `get_selection()`，并且
渲染出的 Strip 没有文本坐标 metadata 或选择样式，所以 transcript 和临时流均不能参与
这套内置机制。`TextArea` 有自己的选择实现，不需要修改。

## 2. Design

新增 `app/tui/widgets.py`，提供 `SelectableRichLog(RichLog)`：

1. `render_line()` 基于 RichLog 已渲染的完整 Strip，给可见字符附加内容坐标 metadata。
2. 当前存在 `text_selection` 时，按字符索引切分 Segment，只给命中范围叠加
   `screen--selection` 样式，保留 Markdown 原有颜色、链接和代码样式。
3. `get_selection()` 将当前 `lines[*].text` 以换行拼接，再用 Textual `Selection.extract()`
   提取可见文本。
4. `selection_updated()` 只刷新显示，不修改消息、Session 或输入状态。
5. Application 将 `#transcript` 与 `#stream-output` 两处实例替换为该子类；其余查询仍可按
   `RichLog` 基类工作。

```text
mouse drag
  -> Textual Screen calculates Selection from Strip offset metadata
  -> SelectableRichLog highlights matching character spans
Cmd+C / Ctrl+C
  -> Screen.get_selected_text
  -> SelectableRichLog.get_selection
  -> App.copy_to_clipboard (OSC 52 + Textual local clipboard)
```

## 3. Unicode and Scrolling

- Selection 的横坐标是 Python 字符索引，而不是终端 Cell 宽度；渲染 metadata 由 Textual
  根据字符与 Cell 宽度换算，因此中文宽字符仍按字符提取。
- 选择样式在完整行上按字符切分，随后才按 Cell 进行水平裁剪，避免中文错位。
- metadata 使用当前水平滚动偏移和内容行号；复制文本使用未裁剪的完整可见消息行。
- RichLog 的行数裁剪仍由原组件负责，不复制已经从组件中淘汰的内容。

## 4. Errors and Boundaries

- 没有选择时沿用 Textual `SkipAction`，不响铃、不写 transcript。
- OSC 52 是否真正进入系统剪贴板由终端支持决定；无头测试以 `app.clipboard` 为准。
- 不调用系统命令、不访问文件、不添加依赖。
- `/clear` 调用 RichLog 既有 `clear()` 后，选择内容自然失效；若 Textual 仍持有旧选择，组件
  返回空字符串而不是历史内容。

## 5. Tests

- 专用 Widget：中文单行、多行 Selection 提取。
- 选择高亮：渲染 Strip 包含选择样式且保留文本。
- Application：两处组件均为 SelectableRichLog。
- Markdown：复制渲染后的可见文本，不含源标记。
- Screen copy：执行内置动作后 `app.clipboard` 为选中文本。
- 回归：现有 `tests/test_tui.py` 全部通过。

## 6. Risks and Rollback

- 风险：依赖 RichLog 的 `lines` 公共属性及 Textual Selection 契约；版本升级时需要回归测试。
- 风险：终端禁用 OSC 52 时系统剪贴板不更新，但 Textual 本地剪贴板仍保存选中内容；本期不扩展。
- 性能：只有选择激活时才重建选择样式 Segment；普通渲染沿用 RichLog 缓存路径。
- 回滚：把两处组件恢复为 `RichLog` 并删除 `app/tui/widgets.py`，不涉及数据迁移。
