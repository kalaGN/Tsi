# 模型日志可读格式设计

## 状态

已完成（2026-08-12）。

## 现状

`configure_model_logging()` 为 StreamHandler 和 RotatingFileHandler 安装同一个 `_ModelEventJsonFormatter`，因此 stderr 与文件内容完全相同。TUI 通过 `enable_stream=False` 只保留文件 Handler。

## 架构决策

保持事件数据和输出通道分离：

```text
事件生产函数 + _EVENT_FIELDS 白名单
                 |
                 +-> StreamHandler -> _ModelEventJsonFormatter -> 单行 JSON
                 |
                 +-> RotatingFileHandler -> _ModelEventReadableFormatter -> 中文分块
```

- 不修改八类事件的生产函数和 `extra` 字段。
- 新增文件专属 Formatter，避免为可读性牺牲 stderr 的结构化采集能力。
- Formatter 根据事件名称选择中文标签、元数据和内容区，未知事件仍由白名单机制阻止进入正常路径。
- 使用标准库 `ZoneInfo("Asia/Shanghai")` 格式化本地时间。

## 文件格式契约

每个事件包含：

```text
时间：2026-08-12 14:32:18.126 +08:00
事件：工具结果
请求ID：...
调用ID：...
工具：read_workspace_file
状态：成功
耗时：2.73 ms
输出长度：1256 字符

【工具输出】
{
  "ok": true
}
================================================================================
```

事件字段映射：

| 事件 | 元数据 | 内容区 |
| --- | --- | --- |
| 模型请求 | request/provider/model/输入长度 | 输入内容 |
| 模型响应 | request/provider/model/输出长度 | 输出内容 |
| HTTP 请求 | request/provider/model/method/url/timeout | Header、请求体 |
| HTTP 响应 | request/provider/model/status/duration/content-type | 无 |
| HTTP 错误 | request/provider/model/error/duration | 无 |
| 工具调用 | request/call/tool/参数长度 | 工具参数 |
| 工具结果 | request/call/tool/status/duration/输出长度 | 工具输出 |
| 工具审批 | request/call/tool/是否批准/文件数/Diff 长度/duration | 无 |

## 内容格式化

- Mapping/List 直接使用 `json.dumps(..., ensure_ascii=False, indent=2)`。
- 工具参数和结果为字符串：先尝试 `json.loads()`，成功后缩进输出，失败则保持原文。
- 普通输入输出不尝试 JSON 解析，避免模型回答形似 JSON 时改变正文。
- 空内容不创建内容区。

## 异常与安全

- Formatter 只访问 `_EVENT_FIELDS` 已允许字段。
- JSON 美化失败退化为 `str(value)`，不得抛出异常影响日志调用。
- Authorization 仍固定为 `Bearer [REDACTED]`。
- 不增加原始响应体、异常对象或环境信息。

## 性能与轮转

- 美化仅发生在本地文件 Handler，HTTP stderr 不承担缩进序列化成本。
- 保持 10 MiB 单文件和 5 个备份；多行事件按实际编码后大小参与轮转。
- 当前没有日志吞吐基线，性能影响标记为待验证；本项目模型网络耗时远高于本地格式化成本。

## 测试设计

- 精确验证中文字段、北京时间、分隔线和内容区。
- 验证 JSON 两空格缩进、中文不转义、普通文本换行保持。
- 验证 stderr 仍为单行 JSON 且字段集合不变。
- 验证 TUI file-only、轮转和文件不可用降级语义。
- 使用测试生成的真实文件片段进行人工样例检查。

## 风险与回滚

- 风险：依赖文件单行 JSON 的本地脚本将失效。缓解：stderr JSON 契约不变；文档明确文件转为人读格式。
- 风险：多行事件在并发请求时按事件块交错。单次 logging Handler emit 持锁写入，单个事件块不会被拆开。
- 回滚：删除可读 Formatter 并让文件 Handler 恢复 JSON Formatter，不涉及数据迁移。
