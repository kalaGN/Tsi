# TUI 技能命令设计

状态：已完成（2026-09-05）
创建日期：2026-09-05
对应需求：[TUI 技能命令需求](../spec/20260905-TUI技能命令-需求.md)

## 1. 现状

`ChatTuiApp.action_submit_prompt()` 已实现 `/clear`，并在启动、持久化失败和输入历史场景中有测试。`SkillRuntime` 持有当前不可变 `SkillCatalog`，但只对 TUI 暴露数量与错误状态，无法安全展示清单。

## 2. 方案

在 `app/runtime/skill_runtime.py` 增加不可变 `AvailableSkill` 摘要和 `available_skills()`：从当前内存 Catalog 生成按名称排序的名称、描述、相对入口路径，不读取磁盘，也不返回正文或绝对路径。

在 `ChatTuiApp` 增加 `/skills` 本地命令分支和专用渲染方法：

```text
输入 /skills
  -> 确认当前无活跃请求
  -> 从 SkillRuntime 读取内存摘要
  -> System 消息展示清单或空/错误状态
  -> 清空输入框
  -> 不调用 ChatSession.send
```

`/clear` 保持原实现，仅同步文档和回归测试，不创建第二套清理逻辑。

## 3. 边界

- Runtime 摘要是只读值对象，TUI 不直接访问 Catalog 内部 Mapping。
- `/skills` 不改变运行状态、会话消息和输入历史。
- Catalog 错误继续使用运行时已有安全错误；界面不显示本地绝对路径。
- 不增加依赖、网络、文件 I/O 或后台任务。
