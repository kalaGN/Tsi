# 运行与测试日志隔离设计

状态：已完成（2026-09-06）
创建日期：2026-09-06
对应需求：[运行与测试日志隔离需求](../spec/20260906-运行与测试日志隔离-需求.md)

## 1. 现状

`configure_model_logging()` 在未传入 `log_path` 时使用单一常量 `logs/model-calls.log`。`app.application` 在创建 FastAPI 应用时调用默认配置，TUI 入口同样使用默认路径。Pytest 先导入这些模块后，后续模型或工具事件可写入真实运行文件。

日志 Logger 是进程级单例，`configure_model_logging()` 已按 Handler 类型幂等：一旦测试在导入应用前注册文件 Handler，应用的默认配置不会再添加第二个文件 Handler。

## 2. 方案

```text
app/observability/model_logging.py
  LOG_ROOT
  RUNTIME_LOG_PATH = logs/runtime/model-calls.log
  TEST_LOG_PATH    = logs/tests/model-calls.log
  DEFAULT_LOG_PATH = RUNTIME_LOG_PATH

tests/conftest.py
  在测试模块收集前执行
  configure_model_logging(log_path=TEST_LOG_PATH)

app.application / app.tui.__main__
  保持默认调用
  -> logs/runtime/model-calls.log
```

运行路径仍由生产入口的默认值决定；测试路径由 Pytest 根级 `conftest.py` 显式注册。不使用 `PYTEST_CURRENT_TEST`、调用栈或进程名自动猜测，也不引入可写任意路径的环境变量。

## 3. 配置契约

- `configure_model_logging(log_path=None)` 使用 `RUNTIME_LOG_PATH`。
- `configure_model_logging(log_path=path)` 继续使用调用方显式路径，供 Pytest 和既有单元测试隔离。
- `tests/conftest.py` 只传入固定 `TEST_LOG_PATH`，不改变日志格式、stderr 或级别。
- 文件 Handler 延迟打开，只有真正产生事件时才创建文件；目录仍在配置时确保存在。

## 4. 测试设计

1. 断言运行与测试常量均在项目 `logs/` 下，且父目录分别为 `runtime` 和 `tests`。
2. 断言无 `log_path` 时 Handler 指向运行日志。
3. 断言显式 `log_path` 仍优先，不受默认目录影响。
4. 新增独立的 Pytest 隔离回归，确认收集期注册的文件 Handler 指向 `TEST_LOG_PATH`。
5. 保留既有格式、脱敏、轮转、TUI 无 stderr 和错误隔离测试。

自动化测试不调用真实外部模型。

## 5. 异常与降级

- 运行或测试目录不可创建时，仍沿用当前错误隔离：不阻断应用或测试。
- HTTP 可用时继续写 stderr JSON；TUI `enable_stream=False` 时继续静默放弃不可用的文件日志。
- 日志事件本身不新增“测试/运行”字段，来源由不可混淆的文件路径表达。

## 6. 安全与性能

- 日志仍可包含完整模型输入输出，两个目录都不得进入 Git，也不向 Workspace 工具开放。
- 不增加每事件分支或重复写入；单进程仍只保留一个文件 Handler，性能开销不变。
- 两类日志独立轮转，各自最多保留当前文件和 5 个备份。

## 7. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| `conftest.py` 加载过晚 | 放在 `tests/` 根目录，由 Pytest 在收集测试模块前导入 |
| 单元测试重配全局 Logger | 沿用既有 Handler 移除/恢复夹具，显式路径测试不依赖全局默认 |
| 旧脚本继续查看旧路径 | README 和故障文档明确新路径，旧文件保留供历史查询 |
| 测试日志无限增长 | 复用 10 MiB/5 备份轮转，与运行日志分开计算 |

## 8. 兼容与回滚

- 公开 HTTP/TUI/Provider 契约不变，`configure_model_logging(log_path=...)` 调用不变。
- 唯一用户可见变化是默认日志的新路径。
- 回滚时恢复原 `DEFAULT_LOG_PATH`并删除测试预配置；已产生的新日志保留，不自动合并。

## 9. 验证命令

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q
.venv/bin/python -m compileall -q main.py app tools tests
.venv/bin/python -m pip check
git diff --check
```
