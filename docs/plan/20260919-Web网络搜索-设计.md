# Web 网络搜索设计

状态：已完成（2026-09-19）

对应需求：[Web 网络搜索需求](../spec/20260919-Web网络搜索-需求.md)

## 方案

`WebSearchTool` 是无本地副作用的受限读取工具，固定向 `https://google.serper.dev/search` 发送 `POST`。模型只提供 `query` 和可选 `limit`；供应商地址、认证 Header、区域和语言由宿主固定。

Web 的请求级 Registry 新增独立 `web_search` 组。首个模型步骤仍只看到 `activate_tool_groups`，需要搜索时激活该组，下一步骤才获得工具 Schema。HTTP 默认 Registry 直接包含网络搜索；TUI 构造路径不包含该工具，避免无意扩大现有终端能力。

## 安全与可靠性

- `SERPER_API_KEY` 仅在工具执行时从宿主环境读取，不进入 Tool Schema 或返回值。
- 查询去除首尾空白且限制 500 字符；`limit` 必须是 1–10 的真实整数。
- 使用固定 10 秒总超时、禁用环境代理继承，并把响应体限制为 1 MiB。
- 只保留 `organic` 中合法字符串字段，每个字段截断到固定长度，最多返回请求数量。
- 缺配置、网络失败、非 2xx、畸形或超大响应均返回有限原因码，不暴露异常、响应体或密钥。
- 工具为 `READ_ONLY`，Web 自动执行，不进入文件 Diff 审批协调器。

## 验证

使用 `httpx.MockTransport` 覆盖成功、配置缺失、参数非法、HTTP 失败、JSON 畸形和响应上限；Registry 测试验证 Web 可激活且 TUI 不新增搜索组。最后执行需求文档列出的完整门禁。

## 回滚

删除 Web `web_search` 工具组和 HTTP 默认注册即可停用；没有持久化数据或迁移步骤。
