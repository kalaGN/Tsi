# 模型响应性能优化设计

状态：已完成（2026-09-20）

对应需求：[模型响应性能优化需求](../spec/20260920-模型响应性能优化-需求.md)

## 方案

每个真实 Provider Turn 延迟创建一个 `httpx.AsyncClient`，后续工具续接步骤复用该实例。Turn 在最终文本、异常和 Runtime `finally` 中幂等关闭；统一 Turn 契约提供 `aclose()`，Runtime 对历史 Fake 保持兼容。

SSE 客户端以一次请求开始的单调时钟记录 `response_headers_ms`、`first_event_ms`、`first_text_ms` 与现有 `duration_ms`。Provider 的事件解析函数返回该事件是否发布了可展示文本，因此 reasoning、工具参数和 `[DONE]` 不会被误算为首文本。

新增 `read_workspace_files`，参数为 1–4 个 `{path,start_line,max_lines}`。实现复用单文件读取逻辑，每个片段和聚合结果均受既有输出上限约束；任一项非法时整次调用失败，不返回部分结果。

## 风险与恢复

- 连接生命周期遗漏可能造成资源泄漏：Runtime `finally` 与 Provider 自关闭双保险，关闭必须幂等。
- 新计时字段改变日志契约：同步 JSON 白名单、可读 Formatter 和精确测试。
- 批量结果扩大上下文：总输出继续受 Registry 和工具内部字节上限约束。
- 回滚时可分别恢复 HTTP 客户端、日志字段和批量工具，无数据迁移。
