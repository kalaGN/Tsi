# Tauri 独立打包设计

对应需求：[Tauri 独立打包需求](../spec/20260923-Tauri独立打包-需求.md)

## 启动链

`Tsi.app → Tauri Rust Host → PyInstaller sidecar → Uvicorn(127.0.0.1:随机端口) → /ui`

Rust Host 生成随机令牌并通过子进程环境传给 sidecar。sidecar 初始化用户数据目录、加载私有 `.env`，待 Uvicorn 已开始接收请求后向 stdout 发送有界 `TSI_READY:<端口>`。Host 按行解析就绪消息后导航唯一 WebView 到本机 URL；超时或子进程退出时在启动页显示中文错误。主窗口关闭时通过 stdin 通知 sidecar 正常退出；宿主异常退出导致 stdin 关闭时也会停止服务，避免 PyInstaller 单文件工作进程残留。

WebView 的文档初始化脚本仅在预期 loopback 页面上设置内存中的令牌；现有 `api()` 为同源 `/ui/api/*` 请求添加令牌 Header。桌面模式下 FastAPI 中间件校验 Header，普通 HTTP 模式不启用。导航限制在 sidecar 的实际地址，页面不获得 shell 权限。

## 数据与构建

`local_paths.py` 根据可选桌面环境变量解析数据、日志根目录；普通启动仍保持项目 `data/`、`logs/`。PyInstaller 显式收集 Web 静态资源；构建脚本按 Rust 目标三元组命名 sidecar 并调用 Cargo Tauri CLI。`src-tauri/` 只包含壳代码、启动页、配置和最小 capability。

## 验证

- Python：路径解析、桌面 API 令牌、sidecar 就绪输出与静态资源。
- Rust：运行脚本构建 `.app` 并检查 sidecar 与图标已入包。
- 手动：启动、关闭、重启恢复、未授权本机请求拒绝、中文输入和流式输出。
