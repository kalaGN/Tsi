# 模型配置迁移到设置：设计

对应需求：[模型配置迁移到设置需求](../spec/20260923-模型配置迁移到设置-需求.md)。

## 数据与边界

`ModelConfigStore` 在 `data_root()/model-config.json` 保存固定 DeepSeek、阿里云配置：版本、修订号、各 Provider 的候选模型与 API Key。当前模型选择沿用独立的 `model-selection.json`。文件是本机明文，仅限当前用户读写；读取有大小、结构、权限和符号链接校验，写入采用 `0600` 临时文件、`fsync`、原子替换。对外只返回 `api_key_configured` 布尔值，不回传任何 Key 字符。

保留低层 `factory.py` 的显式配置映射接口以供测试和 Provider 构造；生产 Web/TUI 启动时从 `ModelConfigStore` 获取模型配置，不再从进程环境提取模型字段。源码 Web 与 TUI 共享仓库 `data/`；Tauri Sidecar 继承已有 `TSI_DATA_ROOT`，自然使用应用私有 `data/`。其他非模型环境变量照旧。

## 请求链与更新

`GET /ui/api/model-config` 返回脱敏 Provider 配置与修订号；`PUT` 接受固定字段、修订号和 Key 操作 `keep/set/clear`，经过现有 loopback/同源/桌面令牌边界，严格限制正文大小。运行中请求不允许更改模型配置（409）；成功保存后 Web Service 重建模型候选与 Provider，替换已缓存会话 Provider，下一轮请求生效。写盘失败保留旧内存配置；页面不会把 Key 放入 LocalStorage。

TUI 启动读取同一份源码配置并恢复现有模型选择；`/model` 继续只作选择。没有 Key 时可以启动，但禁止发送并提示通过 Web 设置配置；TUI 不新增终端密钥输入。

## 风险与验证

- 明文密钥泄漏：独立私有文件、权限与日志/响应不暴露；不支持自动迁移旧 `.env`。
- “设置只写不读”：测试从保存接口穿过生产 Web Service 到下一次模型请求，并验证 TUI 重启后的候选与 Provider。
- 旧测试依赖注入环境映射：保留显式测试注入入口，但无参生产入口只使用配置文件。
- 断电或旧页面覆盖：版本修订号、防重复键、临时文件原子替换；无效文件拒绝覆盖。同一配置文件不支持多个写进程同时保存；当前桌面与源码数据目录隔离，单 Web 服务内通过运行状态串行操作。
