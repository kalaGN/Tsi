# 服务配置：设计

对应需求：[服务配置需求](../spec/20260928-服务配置-需求.md)。

## 结构

```text
代码注册表（目前 serper）→ 服务页字段与服务 ID 白名单
                              ↓
设置 → 服务 → 同源 API → 私有 service-config.json
                                  ↓
Web 下一次 web_search → 读取 serper Key → 固定 Serper 上游
```

注册表声明已支持的服务及字段类型、展示名和消费方。本版仅注册 `serper.api_key`，未来加服务时必须同时添加实际消费代码及测试；页面不能创建任意 Key／URL。配置文件为版本、修订号和 `services` 映射；公开视图按注册表输出字段的 `configured` 状态，不含任何秘密值。

写操作针对一个服务，显式 `set`／`clear` 指定密钥动作并携带预期修订号。存储沿用模型配置的严格校验、私有目录、原子替换和冲突检查，但不把服务 Key 混入模型配置或会话状态。配置文件损坏或权限不安全时失败关闭，不以 `.env` 值静默回退。

`WebSearchTool` 通过小型 Key 读取接口在调用时拿最新值；Web 工具注册走这一路径。TUI 当前没有搜索工具，本次不新增。保留测试用显式假 Key 注入，避免生产调用读取测试机环境。既有工具返回结构不变。

Web 新增脱敏读取与受限写入接口（例如 `GET /ui/api/service-config`、`PUT /ui/api/service-config/{service_id}`）；服务层负责存储协调与忙碌检查，页面模块负责显示、脏状态和保存／删除。服务菜单作为独立页面分区，不扩张模型设置。

## 风险与验证

- 旧 `.env` 搜索 Key 须手工复制到服务页；README 说明操作和桌面版独立数据目录。
- 日志只允许稳定事件名、服务 ID、结果与原因码，不写 Key、请求体或本机绝对路径。重点验证“保存后下一次真实工具请求 Header 使用新假 Key”，不能只测配置文件。
- 不对未来未接入的服务做空页面或承诺通用任意 HTTP 调用。
