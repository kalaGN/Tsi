# Tsi 助手项目命名需求

## 状态

已实现（2026-09-01）。

## 目标

将当前项目的正式展示名称从 `FastAPI Demo` / `FastAPI Agent TUI` 统一为 `Tsi 助手`，让 README、终端界面和 API 文档使用同一名称，同时不改变现有运行方式与功能契约。

## 用户与成功表现

- 项目维护者在 README 和当前规则、知识文档中看到正式名称 `Tsi 助手`。
- TUI 顶部和终端窗口标题显示 `Tsi 助手`。
- FastAPI 生成的 Swagger/OpenAPI 标题显示 `Tsi 助手`。
- 现有 HTTP、TUI、模型和工具能力不受影响。

## 范围

- 修改 `README.md` 的一级标题和项目介绍。
- 修改 `ChatTuiApp.TITLE`，该值同时用于 Textual 应用标题和页面顶部标题。
- 在 `create_app()` 创建 FastAPI 时设置 `title="Tsi 助手"`。
- 更新 `AGENTS.md`、当前 Rules 索引/规则正文和当前 Knowledge 中的项目名称。
- 增加自动化测试，验证 FastAPI 元数据和 TUI 标题。

## 非目标

- 不重命名仓库目录 `demo/`、`app/` 包或任何 Python 模块。
- 不改变 `.venv/bin/python -m app.tui`、Uvicorn 启动命令或环境变量。
- 不改变 `GET /`、`POST /chat`、OpenAPI 路径、请求响应或错误映射。
- 不修改保留历史决策的旧 Spec、Plan 和 Tasks；其中的 `FastAPI Demo` 继续作为当时项目背景。
- 不新增简称、英文全称、Logo、版本号或发布信息。

## 技术栈与项目结构

- Python 3.11、FastAPI 0.125.0、Textual 8.2.8，版本以 `requirements.txt` 为准。
- HTTP 应用名称在 `app/application.py` 配置。
- TUI 名称在 `app/tui/application.py` 配置。
- 当前事实文档位于根目录、`docs/rules/` 和 `docs/knowledge/`。
- 不新增依赖或目录层级。

## 代码风格

名称使用单一常量值，不添加仅为本次改名服务的新配置层：

```python
application = FastAPI(title="Tsi 助手")

class ChatTuiApp(App[None]):
    TITLE = "Tsi 助手"
```

保持现有中文必要注释和直接控制流，不进行无关重构。

## 测试策略

- HTTP 测试断言 `app.title == "Tsi 助手"` 及 `/openapi.json` 的 `info.title`。
- TUI 无头测试断言应用 `TITLE` 与 `#title` 可见内容。
- 使用文本检索确认当前入口文档不再以旧名称描述项目；历史文档排除在此检查之外。
- 运行项目全量测试、语法、依赖和差异检查。

## 边界

### 始终执行

- 正式名称精确使用 `Tsi 助手`，保留大小写和中间空格。
- 同步运行时展示、当前文档和测试。
- 保持公开 HTTP 契约与启动命令不变。

### 修改前另行确认

- 重命名磁盘目录、Python 包、模块、命令、API 路径或会话文件。
- 增加英文全称、Logo、版本或发布渠道。

### 禁止

- 修改历史 Spec 来伪造历史状态。
- 为名称配置引入依赖或环境变量。
- 将 `.env`、密钥或本地数据加入 Git。
