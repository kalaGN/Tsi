# TUI 命令预览

用户已授权实施命令预览方案。

## 行为与验收

- 空闲时输入 `/` 显示 `/clear`、`/skills`、`/quit` 及中文说明；按前缀过滤。
- 候选位于输入框上方，输入焦点保持不变，方向键循环选择。
- Tab/Enter 只补全选中项，再次 Enter 执行；完整命令保留直接执行方式。
- Esc 优先关闭候选并保留原文，随后恢复既有清空输入和退出行为。
- 无匹配项、多行、包含空白及请求执行期间不显示候选；普通输入仍按既有逻辑处理。
- 预览不访问模型、文件系统，不写会话或输入历史。

## 实现与验证

在现有 Textual 应用中使用隐藏的 Static 展示有限候选，监听输入变化，并在键盘动作中优先处理候选。不增加依赖或改变 HTTP、工具审批协议。

测试覆盖前缀过滤、选择补全、执行、Esc 优先级和未知命令，回归现有 TUI 测试及全量测试。使用仓库既有 compileall、pytest、pip check、git diff --check 门禁。
