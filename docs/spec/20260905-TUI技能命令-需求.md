# TUI 技能命令需求

状态：已完成（2026-09-05）
创建日期：2026-09-05

## 1. 目标

完善 TUI 的本地清理与 Skill 查看入口：保留现有 `/clear` 清理能力，并增加 `/skills` 命令列出当前运行时真正可用的项目 Skill，方便用户在不调用模型的情况下确认能力清单。

## 2. 命令契约

- `/clear`：清空界面对话、模型上下文、本地持久化历史和输入历史；沿用现有实现。
- `/skills`：列出当前 `SkillRuntime` 已发布 Catalog 中每个 Skill 的名称、描述和项目相对入口路径。
- 两个命令均仅在去除首尾空白后完全匹配时生效，不调用模型，不进入输入历史或会话持久化。
- `/skills` 不重新扫描磁盘；安装成功后读取热刷新发布的新 Catalog，手工修改磁盘仍需重启或下一次成功安装。
- 当前请求执行期间不处理 `/clear` 或 `/skills`，避免隐藏执行状态或读取跨请求状态。

## 3. 展示与异常

- 清单按 Skill 名称稳定排序，以中文系统消息写入对话区。
- 没有可用 Skill 时显示明确空状态。
- Catalog 启动失败时显示安全错误，不泄露绝对路径或 Skill 正文。
- 未启用 `SkillRuntime` 的注入测试或兼容调用显示“技能列表不可用”，不调用模型。

## 4. 非目标

- 不增加 `/help`、`/chat`、技能搜索、安装、启用/禁用或删除命令。
- 不通过 `/skills` 读取 `SKILL.md` 正文、脚本或资源。
- 不修改 HTTP `/chat`、Provider、Session 文件格式和工具协议。

## 5. 验收标准

1. `/clear` 继续完整清理界面、模型上下文、本地文件和输入历史。
2. `/skills` 能展示已发布 Skill 的名称、描述和 `.agents/skills/<name>/SKILL.md` 路径。
3. 空 Catalog、加载错误和无 Runtime 均有稳定本地提示。
4. `/skills` 不调用模型、不写会话、不进入输入历史，也不触发磁盘重扫。
5. 安装热刷新后，下一次执行 `/skills` 能看到新 Skill。
