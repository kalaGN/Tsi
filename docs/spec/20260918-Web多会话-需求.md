# Web 多会话需求

状态：已完成（2026-09-18）

## 1. 目标

把 Web UI 从唯一会话升级为本地持久化多会话。用户可以在左栏新建、切换、重命名和删除会话；每个会话拥有独立的消息、摘要、长期偏好和上下文占比，刷新或重启后恢复最后打开的会话。HTTP `/chat` 与 TUI 行为保持不变。

## 2. 已采用的假设

1. 多会话仅作用于 Web UI，不改造 TUI 的单会话模式。
2. 会话标题默认取首条用户消息去除首尾空白后的前 30 个字符；空会话标题为“新对话”，支持手动重命名。
3. 会话列表按 `updated_at` 倒序展示，首屏最多返回最近 50 个，不做搜索、归档、分页 UI 或云同步。
4. 同一 Web 进程全局只运行一个模型请求；请求期间禁止新建、切换、重命名、删除或清空会话。
5. 删除前由页面二次确认；删除当前会话后自动切换到最近会话，没有其他会话时自动创建空会话。
6. 旧 `data/web-session.json` 在首次启动时迁移成一个“历史对话”，迁移成功后不重复导入。
7. 模型选择、界面设置和 Workspace 仍为项目级共享，不跟随单个会话保存。

## 3. 功能与 API

后端新增会话索引和独立会话文件，建议结构：

```text
data/web-sessions/
├── index.json
└── sessions/
    └── <session-id>.json
```

`session-id` 由服务端生成并严格校验，不接受客户端路径。索引原子写入，至少保存 `id`、`title`、`created_at`、`updated_at` 与当前会话 ID；每个会话文件继续复用 `SessionStore` v2 格式。

新增或调整接口：

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/ui/api/bootstrap` | 返回会话列表、当前会话和当前消息 |
| `POST` | `/ui/api/sessions` | 创建并切换到空会话 |
| `POST` | `/ui/api/sessions/{id}/select` | 切换会话并返回其消息和上下文占比 |
| `PATCH` | `/ui/api/sessions/{id}` | 修改非空标题，最长 80 字符 |
| `DELETE` | `/ui/api/sessions/{id}` | 删除会话并返回新的当前会话 |
| `POST` | `/ui/api/clear` | 只清空当前会话，不删除会话条目 |

所有接口继续执行 loopback 限制；不存在的会话返回 404，非法标题返回 422，请求运行时的变更返回 409。流式请求在开始时绑定当前会话，完成前不得改变目标。

## 4. 页面行为

- 左栏渲染真实会话列表，显示标题和最近更新时间，当前项高亮。
- “新对话”创建独立会话，不再清空当前历史。
- 点击会话完成切换；每个条目提供重命名和删除操作。
- 切换时替换消息区、会话标题、预览文本和上下文占比，不残留上一会话活动状态。
- 窄屏切换成功后自动收起左栏；键盘输入、设置、模型选择和文件区行为保持不变。
- 页面只通过 `textContent` 渲染标题和消息，不把标题解释为 HTML。

## 5. 工程约束

### 5.1 技术栈与结构

- Python 3.11、FastAPI、现有 `ChatSession`/`SessionStore`，不新增依赖。
- 多会话索引和装配放在 `app/webui/`，不把 Web 状态写入通用 Runtime。
- 页面继续使用原生 HTML/CSS/JavaScript，不引入前端构建工具。


## 6. 测试策略

- 存储单测：创建、排序、重命名、删除、当前项恢复、损坏索引、非法 ID、原子写入和旧单会话迁移。
- Service/API 测试：会话隔离、切换恢复、忙碌冲突、404/409/422、删除当前会话后的回退。
- 静态 UI 契约：真实会话列表、操作入口、安全文本渲染和 API 路径。
- 浏览器验收：创建两段不同对话，来回切换并刷新；重命名和删除后状态一致。测试不得调用真实模型。

## 7. 边界

- 必须：持久化写入原子化，文件权限保持 `0600`，ID 与标题严格验证，旧数据先迁移再使用。
- 需另行确认：跨工作区会话、超过 50 条的分页交互、会话导入导出、批量删除或云同步。
- 禁止：客户端提交文件路径、共享可变 `ChatSession`、删除 TUI 会话、记录 API Key、通过减弱测试完成迁移。

## 8. 验收标准

1. 可创建并持久化至少 20 个 Web 会话，每个会话的历史、摘要、偏好和上下文完全隔离。
2. 页面可新建、切换、重命名、删除和清空当前会话，刷新后恢复最后选择。
3. 旧 `data/web-session.json` 自动迁移且内容不丢失、不重复导入。
4. 模型请求期间所有会话结构变更返回明确冲突，完成或取消后恢复可操作状态。
5. 删除当前或最后一个会话后始终得到有效当前会话，不出现无会话或悬空 ID。
6. 非 loopback、路径穿越、非法 ID、空白/超长标题和损坏索引不能扩大读取或写入范围。
7. 原有 HTTP、TUI、模型、工具和 Web 只读安全测试全部通过。
