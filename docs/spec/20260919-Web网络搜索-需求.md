# Web 网络搜索需求

状态：已完成（2026-09-19）

## 目标

让 Web UI 中的模型能够按任务意图调用受限网络搜索工具，查询结果由固定的 Serper.dev Google Search API 提供。工具只执行搜索，不允许模型指定 URL、Header 或请求方法，也不扩大 Workspace、Git、Skill 和脚本权限。

## 配置与命令

- 配置：在 `.env` 中设置 `SERPER_API_KEY`，密钥不得进入代码、文档、日志、测试或 Git。
- 定向测试：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q tests/test_web_search.py tests/test_workspace_tools.py tests/test_webui.py`
- 完整测试：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`
- 编译：`.venv/bin/python -m compileall -q main.py app tools tests`

## 项目结构

- `tools/web_search.py`：固定上游、参数校验、超时、响应边界和安全错误。
- `tools/groups.py`、`tools/workspace.py`：Web 专属 `web_search` 工具组和渐进披露。
- `tools/__init__.py`：HTTP 默认 Registry 注册。
- `tests/test_web_search.py`：无真实网络的工具契约测试。

## 代码风格

使用构造器注入环境和 HTTP Client，测试通过 `httpx.MockTransport` 验证，不调用真实服务：

```python
tool = WebSearchTool(environ={"SERPER_API_KEY": "test-key"}, client=client)
```

## 测试策略

- 参数边界：空白、超长查询，布尔或越界数量，多余参数。
- 配置边界：缺少 API Key 时不发出网络请求且不泄露配置。
- 上游边界：只请求固定 HTTPS 地址；验证 Header、Body、超时、非 2xx、畸形及超大响应。
- Registry：HTTP 可直接使用；Web 初始仅披露激活工具，激活 `web_search` 后可见；TUI 不新增该工具组。

## 边界

- 始终：查询最长 500 字符、结果 1–10 条、固定 Serper URL、响应体和字段有界、错误文案稳定。
- 另行确认：其他搜索供应商、网页正文抓取、任意 URL、搜索历史持久化或独立网络审批。
- 禁止：记录 API Key、把上游异常原文返回模型、使用真实服务做自动测试、让搜索获得文件写入能力。

## 验收标准

1. Web 模型可激活 `web_search` 工具组并调用 `web_search`。
2. 正常响应返回标题、链接和摘要；不配置 Key 时返回稳定的不可用状态。
3. 工具不会接受任意 URL、Header、引擎或请求方法。
4. API Key 不进入模型参数、工具结果和项目日志。
5. HTTP 默认工具继续包含当前时间和网络搜索；TUI 工具组保持不变。
6. 定向测试、完整测试、编译、依赖和 Diff 检查通过。
