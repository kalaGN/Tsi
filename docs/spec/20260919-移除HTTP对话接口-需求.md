# 移除 HTTP 对话接口需求

状态：已完成（2026-09-19）

## 目标

移除对外暴露的无状态聚合 JSON 接口 `POST /chat`，包括其路由、请求/响应模型、错误到状态码的映射和契约测试。本机 Web UI 与 Textual TUI 成为仅有的两个对话入口，两者继续共享 `app/runtime/chat.py` 的 Runtime 语义。FastAPI 服务本身保留，因为 Web UI 挂载在同一个应用上。

## 配置与命令

- 定向测试：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q tests/test_application.py`
- 完整测试：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`
- 编译：`.venv/bin/python -m compileall -q main.py app tools tests`

## 项目结构

- 删除 `app/routers/`：`chat.py` 与包 `__init__.py`。
- `app/application.py`：不再导入和注册 Chat Router。
- `tests/test_chat.py` 收敛为 `tests/test_application.py`：只保留应用装配、根路由和已移除端点测试。
- 同步 `README.md`、`AGENTS.md`、`docs/knowledge/` 与 `docs/rules/` 的当前状态描述。

## 边界

- 始终：Web UI 与 TUI 的对话、审批、会话和统计行为不变；Runtime、Provider、工具与密钥边界不变。
- 另行确认：删除 `app/runtime/chat.py`、`create_default_registry` 或任何会话持久化文件。
- 不做：改动上游 Provider 契约；删除历史 `docs/spec`、`docs/plan`、`docs/tasks` 记录；改写已标注日期的仓库审计快照。
- 禁止：为保留兼容而留下无调用方的对外接口；通过删除或弱化测试制造通过。

## 验收标准

1. `POST /chat` 返回 404，OpenAPI `paths` 不含 `/chat`。
2. `GET /` 与 `/ui` 及其接口行为不变，服务仍只接受 loopback 客户端。
3. Web UI 与 TUI 的对话、审批、会话恢复与 Token 统计不受影响。
4. 完整测试、编译、依赖和 Diff 检查通过。
5. 当前状态文档不再把 HTTP 描述为独立对话入口。
