# Web 设置与统计需求

状态：已完成（2026-09-20）

## 1. 背景

当前 Web UI 通过原生 `dialog` 展示设置。该方式只能承载少量表单，不利于继续扩展模型配置、使用统计和后续桌面端设置能力。页面目前能展示单次请求的 Token、耗时和上下文占比，但没有跨请求、跨重启的聚合统计。

本次将设置从弹窗改成 Web UI 内的独立页面，并以左侧菜单组织设置项；同时增加不包含对话正文的本地使用统计。

## 2. 目标

- 设置不再以弹窗展示，而是在现有 `/ui` 应用内切换到完整页面。
- 设置页面提供固定左侧菜单，第一版包含“通用”“模型”“统计”。
- 支持浏览器前进、后退和刷新后恢复当前设置子页面。
- 持久化 Web UI 的请求结果、Token、耗时和模型使用情况，并在统计页清晰展示。
- 保持现有模型选择持久化、浏览器本地偏好和工具审批安全边界不变。

## 3. 用户场景

1. 用户点击顶部设置按钮后进入独立设置页面，而不是看到弹窗。
2. 用户从左侧菜单切换通用、模型和统计，各页面只展示相关内容。
3. 用户点击“返回对话”或使用浏览器后退键回到原会话，消息和输入草稿不丢失。
4. 用户重启服务后仍能看到累计请求、Token 和耗时统计。
5. 用户可以看到不同模型的调用次数和 Token 使用量，但统计页不展示输入、输出正文或密钥。

## 4. 范围

### 4.1 独立设置页面

- 设置仍由 `/ui` 的原生 HTML、CSS、JavaScript 实现，不引入前端框架或构建工具。
- 使用 URL Hash 表示页面状态：
  - `#/chat`：对话页；
  - `#/settings/general`：通用设置；
  - `#/settings/model`：模型设置；
  - `#/settings/statistics`：统计页面。
- 点击设置入口切换页面，不重新加载应用；浏览器前进、后退和刷新可恢复对应页面。
- 设置页面使用左侧纵向菜单和右侧内容区；窄屏时菜单保持可操作，不覆盖主要内容。
- 页面提供明确的“返回对话”按钮，返回时保留当前会话、消息、右侧面板状态和未发送草稿。
- 现有工具审批仍使用独立弹窗，不随设置弹窗一起移除。

### 4.2 设置菜单

- “通用”继续管理主题、界面密度、发送快捷键和恢复默认值；这些偏好仍保存在浏览器 `localStorage`。
- “模型”列出当前已配置 Provider 与模型，继续复用现有后端模型选择和持久化能力，不显示或编辑 API Key。
- “统计”按需请求本地统计接口；打开其他设置页时不重复拉取统计数据。
- 当前菜单项有明确的文字、图标和选中状态，并支持键盘聚焦。

### 4.3 统计口径

统计范围仅包含 Web UI 发起的模型请求，不混入 TUI、测试、评测或其他入口。

累计统计包括：

- 请求总数；
- 成功、失败和用户取消数量；
- 成功率；
- 有真实 Usage 的请求数；
- 输入 Token、输出 Token 和总 Token；
- 成功请求的平均耗时；
- 按 Provider/模型聚合的请求数和 Token；
- 最近 30 个自然日的请求数、成功数、Token 和平均耗时。

规则：

- 请求被 Web Runtime 接受时计入请求总数；一个请求只记录一个最终结果。
- 正常完成计为成功；上游、协议、工具或内部异常计为失败；用户主动停止计为取消。
- Token 只累计 Provider 返回的真实 Usage；没有 Usage 时不估算，并单独反映 Coverage。
- 平均耗时只基于成功请求，从 Runtime 接受请求到最终完成事件计算。
- 日期边界使用应用运行环境的本地时区；页面明确显示统计口径。

### 4.4 数据持久化与接口

- 聚合数据保存到 `data/web-statistics.json`，使用带版本号的 JSON Schema。
- 写入使用临时文件加原子替换，并限制文件权限；统计写入失败只能记录日志，不能让正常对话失败。
- 日维度数据只保留最近 30 天；模型维度只接受当前实际调用的 Provider/模型标识，不保存任意正文。
- 新增只读 `GET /ui/api/statistics`，继续执行现有 loopback 和同源保护。
- 接口只返回聚合数字、日期及 Provider/模型标识，不返回消息、工具参数、文件路径、会话 ID、密钥或日志正文。
- 文件缺失时返回全零统计；文件损坏时隔离损坏文件、记录错误并从空统计继续运行。

### 4.5 统计页面

- 顶部摘要卡展示累计请求、成功率、总 Token 和平均耗时。
- 展示输入/输出 Token 分项和 Usage 覆盖率，避免把缺失 Usage 误认为零消耗。
- 以波形图展示按天聚合的趋势，支持“近 7 天 / 近 30 天”范围切换，默认显示近 7 天。
- 波形图支持切换请求数、总 Token 和平均耗时三个指标；同一时刻只展示一个指标，避免不同量纲混用。
- 第一版使用项目内原生 SVG 折线与面积填充，不增加图表依赖；零数据日期仍连续展示在时间轴上。
- 图表为每个日期提供可聚焦的数据点和文本摘要，不能只靠颜色传递信息。
- 展示按 Provider/模型聚合的表格，至少包含请求数、输入 Token、输出 Token、总 Token。
- 没有数据、部分请求无 Usage、统计加载失败时给出明确空态或错误提示。

## 5. 非目标

- 不增加统计重置、导出、费用估算、配额告警或云端同步。
- 不统计或合并 TUI、离线评测、测试和已存在日志中的历史数据。
- 不解析模型日志来回填历史统计。
- 不保存或展示提示词、回复正文、工具参数、文件内容、会话标识或 API Key。
- 不新增 React、Vue、数据库、分析 SDK 或外部图表库。
- 不改变对话页三栏布局、Runtime 工具策略、Workspace 审批流程和 TUI 行为。

## 6. 兼容与迁移

- 现有浏览器主题、密度和发送快捷键偏好继续有效。
- 现有模型选择和后端持久化文件继续有效。
- 原设置弹窗删除后，原设置按钮和键盘焦点改为进入设置页面。
- 统计从功能上线后开始累计；不对旧日志或旧会话做追溯迁移。
- `data/web-statistics.json` 不进入 Git，缺失时自动创建。

## 7. 安全与可靠性

- 统计接口与其他 `/ui/api/*` 一样只允许 loopback 客户端。
- Provider/模型标识作为纯文本渲染，不允许注入 HTML。
- 聚合更新必须避免一次请求被重复累计，并能处理请求取消、客户端断开和流式异常。
- 统计文件读取、升级或写入异常不得中断 Web UI 启动和模型对话。
- 自动化测试不得调用真实模型、付费接口或外部网络。

## 8. 验收标准

1. 点击设置按钮进入独立页面，页面具有左侧菜单和右侧内容区，不再存在 `settings-dialog`。
2. 通用、模型、统计三个地址可直接刷新；浏览器前进、后退以及“返回对话”行为正确。
3. 从设置页返回后，当前会话、消息、右侧面板状态和未发送草稿保持不变。
4. 通用设置和模型切换保持现有行为，工具审批弹窗正常工作。
5. Web 请求的成功、失败和取消各只累计一次，重启后统计仍存在。
6. Provider 返回 Usage 时，输入、输出和总 Token 聚合正确；无 Usage 时只降低 Coverage，不制造估算值。
7. 统计页正确展示摘要、模型表格，以及可切换近 7 天/近 30 天和请求数/Token/平均耗时的波形图；图表能处理零值、空数据、部分 Usage 和接口错误。
8. 统计文件不包含消息正文、工具参数、文件路径、会话 ID 或密钥，日数据最多保留 30 天。
9. 统计文件缺失、损坏或暂时不可写时，对话功能仍可使用并有可诊断日志。
10. Web UI 拒绝非 loopback 访问，TUI 与现有会话、工具和模型行为无回归。
11. 相关静态契约、路由、统计持久化和请求生命周期测试通过，完整项目测试通过。
