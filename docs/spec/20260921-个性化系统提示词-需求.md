# 个性化系统提示词需求

状态：已完成（2026-09-22）

## 背景与目标

Web 设置页已有“通用、模型、上下文、统计”，但不能编辑个人使用的系统提示词。用户希望在设置里增加“个性化”菜单，保存自定义提示词，并让后续对话请求自动使用。

## 范围

- 在设置左侧菜单增加“个性化”，支持 `#/settings/personalization` 直接访问、刷新和浏览器前进/后退。
- 页面提供可编辑的多行“自定义系统提示词”、保存按钮、清空操作，以及保存成功/失败状态；未保存的改动不会影响请求。
- 提示词作为本机项目级设置持久化，适用于 Web UI 所有会话的后续模型请求；重启服务后保留。正在进行的请求使用其启动时快照，不中途更换。
- 保留启动目录 `AGENTS.md` 的现有加载行为；自定义提示词在项目规则之后追加，不覆盖项目规则。留空或清空时只使用原有项目规则。
- 后端提供仅限 loopback、写入校验同源的读取/保存接口；请求设大小上限，文件使用限制权限与原子写入，并通过修订号避免多个页面相互覆盖。
- 页面说明：提示词会发送给所选模型服务，并可能出现在本机模型请求日志中；不要填写密钥。界面仅以文本方式展示内容，不解析 HTML。

## 非目标

- 不编辑或覆盖 `AGENTS.md`；不修改 TUI 的提示词来源。
- 不提供每会话/每模型单独提示词、云同步、模板市场或变量插值。
- 不改变现有会话历史、工具审批和模型切换逻辑。

## 异常与兼容

- 设置文件缺失时视为空提示词；损坏或不可读时提供明确错误，不静默覆盖原文件。
- 保存失败时保留原有配置，并向页面展示错误；刷新后可重新读取。
- 现有 Web 会话及设置无需迁移；关闭功能时删除自定义内容即可恢复原有提示词组合。

## 验收标准

1. 设置左侧出现“个性化”；地址可刷新、前进和后退，其他设置页行为不变。
2. 保存后新请求的 system 消息包含原 `AGENTS.md` 和自定义文本，顺序固定；清空后仅保留原有项目规则。
3. 不同 Web 会话共享该设置；服务重启后仍生效；进行中的请求不受保存操作影响。
4. 非 loopback、跨站写入、非法字段、超长内容和过期修订号被拒绝；损坏文件不会被静默重置。
5. 保存失败不会破坏原文件，API 不泄露路径或密钥；页面提示敏感信息与本地日志风险。
6. 使用离线测试覆盖提示词组合、持久化、接口、页面路由和快照行为，不调用真实模型。

## 已确认边界

- 按“Web UI 全会话共享、本机持久化”实现；TUI 暂不读取该设置。
- 自定义内容追加到 `AGENTS.md` 后，不替换项目规则。
