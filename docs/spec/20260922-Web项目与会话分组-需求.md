# Web 项目与会话分组需求

状态：已确认并实现（2026-09-22）

## 目标

在 Web UI 左侧按项目组织会话，让用户为本地项目指定名称和工作目录，并在不同项目的会话间切换。项目切换必须同时切换文件浏览、工具 Workspace 根目录和该目录直属 `AGENTS.md`，不能只改变侧栏显示。保留现有 Web 会话历史。

## 范围与交互

1. 侧栏显示项目列表；每个项目下展示其会话，并提供“新增项目”和当前项目内“新建会话”操作。点击会话会同时选中其所属项目。空项目仍显示，可直接新建会话。
2. 新增项目填写名称和本机已有绝对目录路径。项目可重命名、修改路径；修改路径后，该项目已有会话在下一轮请求使用新路径，旧消息原样保留，并给出清晰提示。首版不删除项目，也不自动移动项目目录。
3. 首次升级时，以当前 Web 服务启动目录创建默认项目；现有 `data/web-sessions/` 内的会话及当前选择原样关联到该项目，失败时保留原索引与内容，不以空会话覆盖。
4. 项目元数据持久化于服务本机 `data/`，不写入被选择的项目目录。刷新/重启后恢复项目、归属关系和最后选择的会话。会话内容仍用已有独立 `SessionStore`。
5. 只接受存在的真实目录与绝对路径；拒绝文件、符号链接目标、文件系统根目录及家目录等过宽范围。路径不存在或变为不可用时显示错误，不静默回退到其他项目。
6. 切换项目或修改路径时，仅影响后续模型请求。运行中禁止切换、修改项目/会话；运行中的工具审批始终绑定原请求和原 Workspace。所有文件操作继续使用 `WorkspacePolicy` 和现有逐次写审批。
7. 模型选择、上下文参数、个性化系统提示词与聚合统计首版保持全局；TUI 的启动目录、会话及 Skill 行为不变。项目路径不会注入模型对话正文或普通运行日志，但会在本机项目设置和 Workspace 标识处展示。

## 数据与接口边界

- 项目记录包含稳定 ID、名称和规范化绝对路径；默认项目使用固定 ID 以便幂等迁移，新项目使用随机 ID。会话索引增加 `project_id`。服务端验证归属，不相信浏览器传来的路径作为任意工具根目录。
- 新增/修改项目使用仅限 loopback、同源 JSON 的有界 API，限制名称/路径长度与项目数量；非法或失效目录返回可读中文错误。
- 项目索引与旧会话索引迁移需要原子保存和可恢复策略；重复启动迁移必须幂等。原会话正文文件不得重写或搬迁。
- 项目级 `AGENTS.md` 沿用现有大小/类型限制；加载失败给提示，不能沿用上一个项目的规则。

## 项目结构与执行命令

- `app/webui/sessions.py`：会话元数据及兼容迁移；`app/webui/` 内新增项目索引模块；`service.py` 绑定项目 Workspace 与请求快照；`router.py` 暴露受限 API。
- `app/webui/static/`：侧栏项目分组、创建/编辑交互；`tests/test_web_sessions.py`、`tests/test_webui.py` 和新增项目索引测试覆盖行为。
- 安装：`.venv/bin/python -m pip install -r requirements.txt`；启动：`.venv/bin/python -m uvicorn main:app --reload --env-file .env`。
- 验证：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q tests/test_web_sessions.py tests/test_webui.py`；完整测试：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`；再执行 `.venv/bin/python -m compileall -q main.py app tools tests` 和 `git diff --check`。

## 代码风格与测试策略

沿用现有 Python 类型标注、显式异常和中文边界注释，不新增前端框架。示例：

```python
def select_project(self, project_id: str) -> dict[str, object]:
    """仅在空闲时切换项目，并返回一致的会话与 Workspace 快照。"""
    self._require_idle("切换")
    project = self.projects.require(project_id)
    self._activate_project(project)
    return self.bootstrap()
```

单元测试覆盖项目索引校验/持久化/迁移；服务与路由测试覆盖跨项目会话、请求快照、路径失效、运行中冲突和审批隔离；前端契约及必要的本机手工体验检查覆盖分组与切换。测试不得调用真实模型。

## 边界与验收

- 始终执行：先验证路径和现有数据，再保存；保留旧会话；每次切换后重新构建受限 Workspace；跑相关测试。
- 先确认：项目路径变更对已有会话的含义；未来删除项目/迁移会话的操作；任何新增依赖或扩大到远程访问。
- 绝不执行：未经审批写文件、把项目路径当作不受限工具参数、丢弃旧会话、记录密钥或自动提交。

验收标准：能新增两个不同路径的项目，各自建立会话；在会话之间切换时，左侧选中态、右侧文件树、工具访问根目录和 `AGENTS.md` 与项目一致；刷新/重启后归属与历史保持；非法目录和运行中切换被拒绝且不会影响正在执行的请求；旧 Web 历史迁移一次且可恢复。
