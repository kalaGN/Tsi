# Tauri 独立打包需求

状态：已确认（2026-09-23）

## 目标

在 macOS Apple Silicon 上将现有 Tsi Web UI 打包为可双击启动的 `.app`。应用自行启动和停止 FastAPI，本机无需另开 Uvicorn、安装 Python 或安装 Node。桌面端继续复用现有 Web 会话、模型、工具与审批逻辑。

## 范围与约束

- 桌面壳采用 Tauri 2；前端沿用 `app/webui/static/`，无需 Node 前端构建。
- Python 后端使用 PyInstaller 构建为 Tauri sidecar；构建命令使用 Cargo 版 Tauri CLI。
- 后端只监听 `127.0.0.1` 随机端口；桌面模式的 `/ui/api/*` 必须校验本次启动随机令牌。令牌不能放在 URL、日志或持久化文件中。
- `.app` 启动时创建单窗口，窗口关闭时停止 sidecar。页面不能通过 Tauri IPC 执行任意命令。
- 会话、模型选择、个性化设置、MCP 配置和日志保存在 `~/Library/Application Support/Tsi/`，不能写入 `.app` 包内或临时解包目录。
- API Key 仍由环境变量或用户私有的 Application Support `.env` 提供，不写入安装包。
- 当前只构建 Apple Silicon 未签名 `.app`；签名、公证、DMG、Intel/Universal、自动更新另行处理。

## 验收

1. `scripts/build_macos_tauri.sh` 从项目虚拟环境构建 Python sidecar，再执行 `cargo tauri build --bundles app`；生成物和构建缓存不进入 Git。
2. 双击 `.app` 后自动启动 FastAPI 并打开现有 Web UI；不依赖项目虚拟环境或运行中的外部服务。
3. 桌面模式浏览器直接访问 `/ui/api/bootstrap` 未携带令牌时被拒绝；普通 HTTP 启动的既有接口行为不变。
4. 重启应用后会话与设置仍在，关闭窗口后 sidecar 停止。
5. 相关 Python 测试和 Rust 编译通过；自动化测试不调用真实模型。

## 已知限制

- 首次启动的默认项目为 Application Support 下的空工作区；用户可在页面新增实际项目路径。
- macOS 未签名应用可能被系统阻止直接打开，发布前需另做签名与公证。
