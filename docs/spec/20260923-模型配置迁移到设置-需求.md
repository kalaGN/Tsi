# 模型配置迁移到设置：需求

## 目标与范围

模型供应商、候选模型和 API Key 不再要求写入 `.env`。桌面 `.app`、源码 Web UI 与 TUI 均读取本机持久化模型配置；Web UI「设置 → 模型」负责新增、编辑和删除模型配置，已有模型切换行为继续可用。固定支持当前的 DeepSeek 和阿里云 Provider，不在本次增加自定义接口地址或新供应商。

源码 Web UI 与 TUI 共用项目 `data/` 下的模型配置；独立 `.app` 使用 `~/Library/Application Support/Tsi/data/` 下的模型配置，与源码运行状态隔离。现有 `.env` 中非模型项（例如网络搜索）不受影响。旧模型密钥不自动迁移、不自动删除，避免静默复制或覆盖秘密；用户在新设置中手动录入后自行清理旧 `.env`。

## 用户行为与验收标准

1. 首次启动未配置 API Key 时，Web UI、桌面版、TUI 都能正常进入；界面明确提示前往模型设置，不发起上游请求。
2. Web 模型设置可维护每个 Provider 的 API Key 和有界候选模型列表；保存后无需重启，下一次请求使用新配置。TUI 重新启动后读取同一份源码配置，`/model` 只展示当前可用候选。
3. 允许只修改模型列表而保留已有 Key；删除 Key 必须显式操作。设置读取、Bootstrap、模型选项和错误响应都不得返回 Key 正文或掩码尾号，输入框不会回填旧 Key。
4. 配置文件只包含受支持的 Provider、模型名及 Key，使用版本字段和有界结构；父目录权限 `0700`、文件权限 `0600`，拒绝符号链接、非法结构和超长内容，保存采用原子替换。它是**本机明文文件**，不提供对其他本机进程或拥有同一用户权限者的加密保护。
5. 配置更新与当前进行中的请求隔离：运行中保存返回冲突提示，不替换 Provider；请求结束后保存，新的请求使用新配置；配置损坏或保存失败时不覆盖原文件、不在页面或日志暴露密钥。
6. 原有上下文预算、个性化提示词、模型选择和会话恢复功能保持；历史 `.env` 模型字段不再作为模型配置来源。文档给出首次配置、源码/桌面数据目录及旧配置迁移步骤。

## 工程约束

- 技术栈：Python 3.11、FastAPI、现有原生 HTML/CSS/JS、Textual、Tauri 桌面壳；不为配置功能引入 Node 或数据库。
- 主要位置：`app/services/llm/` 保留 Provider 构造，`app/runtime/` 增加模型配置存储与状态协调，`app/webui/` 增加设置接口和页面，`app/tui/` 读取同一配置，`tests/` 添加无真实密钥的单元与生产路径回归测试。
- 风格示例：`ModelConfigStore.save(expected_revision=revision, provider="deepseek", models=["deepseek-v4-flash"], api_key_action="keep")`；接口与存储字段固定，中文用户提示不带底层异常和密钥。
- 常用验证：`.venv/bin/python -m compileall -q main.py app tools tests`；`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`；`.venv/bin/python -m pip check`；`git diff --check`；桌面壳再执行 `bash scripts/build_macos_tauri.sh`。
- 始终：限制请求体和文件大小、严格校验字段、显式排除秘密日志、补测试并同步中文文档。先确认：任何自动导入或删除旧 `.env`、变更支持的 Provider。禁止：密钥进入 Git、Bootstrap、模型日志、测试快照或浏览器持久化存储。

## 已确认的交互细节

首版由 Web 设置页维护 API Key 和候选模型；TUI 读取配置并继续通过 `/model` 切换，不增加在终端输入 API Key 的命令。
