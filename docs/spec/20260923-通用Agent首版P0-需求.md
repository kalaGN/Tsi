# 通用 Agent 首版 P0：需求

## 目标与已确认假设

在 Tsi 现有单 Agent Runtime 上增加可选长任务模式；普通聊天保持原行为。本版仅面向本机、单个活动任务，不增加多 Agent、任意 Shell、公网多用户或未经审批的写权限。任务中途崩溃后的写操作不自动重放，须检查证据后由用户决定继续。

## 用户行为与验收

1. 用户可在 Web/TUI 创建含目标和可验证条件的任务；启动、步骤、等待审批、验证、完成、失败、取消和需人工检查都有可恢复状态。任务关联现有会话，重启可查看状态及有限诊断。
2. 普通聊天与任务共用当前 `ChatSession`、Provider 和工具白名单；任务模式不赋予新的工具权限。Web/TUI 可用工具可以不同，但工具风险与审批策略有唯一声明来源。
3. 工具组激活只是披露，不是授权；写入、执行和外部 MCP 继续按当前调用审批。已拒绝、过期或重启前的审批不能在恢复后自动通过。
4. 完成状态必须来自确定性验收证据；检查不通过或条件无法检查时标记需人工处理。模型自述“完成”不能代替验收。
5. 崩溃、断流或取消后的进行中步骤标记需人工检查；已执行写操作不得自动重放。仅在用户确认后从安全边界继续，且不清除现有工作区修改。
6. 任务最多 3 次显式执行；每轮继续受已有模型 Token/工具调用限制，Web 单轮最长 10 分钟。达到上限后不无限循环或自动重试。跨轮累计 Token 配额留待下一版。

## 技术与边界

- 技术栈：Python 3.11、现有 FastAPI/Web UI、Textual、JSON 私有状态文件和评测框架；首版不增加依赖或数据库。
- 主要位置：`app/runtime/` 任务状态与执行，`tools/` 能力策略，`app/webui/` 和 `app/tui/` 入口，`tests/` 与 `evals/` 验收。
- 常用验证：`.venv/bin/python -m compileall -q main.py app tools tests`；`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`；`.venv/bin/python -m pip check`；`git diff --check`。
- 始终：原子保存、私有权限、无秘密的状态响应、审批失效、任务预算。先确认：增加公网用户、自动重放写工具、引入任意命令或新的后台调度基础设施。禁止：绕过审批、把模型输出直接判作已验收、覆盖现有会话和工作区状态。

## 首版可验证条件

只支持固定检查类型：文件存在/不存在、文件 SHA-256、固定项目检查 `compile`、`test_all`、`pip_check`、`diff_check`。任务可以有多个条件且须全部通过；没有条件时终态为“待人工确认”。不执行模型生成的任意命令或脚本作为验收器。
