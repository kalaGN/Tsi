# 任务预判与拆解：需求

## 目标

Tsi 在处理每一条 Web/TUI 聊天输入和显式长任务前，先做一次只读、无工具的任务判断。简单请求继续正常执行；复杂请求展示简短步骤和完成标准，等待用户确认后才开始模型工具循环；信息不足时先询问，不执行原任务。

## 已确认决策与假设

- 已确认：覆盖所有聊天请求，而非仅长任务；复杂任务先展示计划，用户确认后执行。
- 假设：简单请求在判断后自动执行；信息不足时只展示澄清问题。若此假设不符，实施前调整。
- 预判会增加一次模型调用和等待时间；不能把它描述为零成本的本地分类。
- 显式长任务的原有验收、最多 3 次执行、审批及中断恢复规则保持不变。预判失败不消耗执行次数。

## 可观察行为

1. 每条输入先产生 `direct`、`planned` 或 `clarify` 之一；判断结果包含有限理由。复杂任务的计划最多 6 步，每步有可检查的产出，不能包含密钥或原始工具参数。
2. `direct` 自动进入既有对话/任务执行路径；`planned` 先展示计划并等待明确“执行”或“取消”；`clarify` 展示问题，等待用户补充新输入。
3. 计划未确认前不得执行 Workspace 写入、脚本、Git、MCP 或任何模型工具调用；确认后的执行仍遵守原有逐次审批。
4. Web 页面和 TUI 都能查看、确认或放弃当前待确认计划；计划仅属于生成它的会话与项目。切换会话/项目、重启或更换模型后不能误执行旧计划。
5. 预判报错、超时、格式无效或取消时，原输入不进入执行阶段，并给出可重试的中文提示。
6. 原有 `/ui/api/chat` 流式协议和 TUI 普通聊天仍可用；新增计划事件不得暴露 Provider 原始响应或密钥。

## 实现范围与命令

- Python 3.11；共享实现放在 `app/runtime/`，Web 接口和页面放在 `app/webui/`，TUI 操作放在 `app/tui/`，测试放在 `tests/`。不新增外部服务、依赖或任意 Shell 能力。
- 启动：`.venv/bin/python -m uvicorn main:app --reload --env-file .env` 或 `.venv/bin/python -m app.tui`。
- 检查：`.venv/bin/python -m compileall -q main.py app tools tests`、`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`、`.venv/bin/python -m pip check`、`git diff --check`。
- 沿用现有类型标注、中文用户提示和必要边界注释；测试使用假 Provider，不调用真实付费接口。

## 边界

- 始终：预判只读、输出有界、严格解析、按会话绑定；异常时失败关闭，不跳过预判直接执行。
- 先确认：是否让简单请求也暂停等待确认、跨重启恢复待确认计划、增加新的任务工具或持久化格式。
- 禁止：预判阶段执行工具、用计划代替长任务确定性验收、绕过文件修改审批、将原始模型报文直接返回页面。

## 验收

- Web/TUI 的直接、复杂、澄清、无效输出、取消和跨会话误确认都有测试；复杂任务在确认前工具调用数为零。
- 确认后只执行一次原输入；拒绝或重启后不自动继续；显式长任务的 `attempts` 在预判前保持不变。
- 生产路径测试证明保存的模型选择影响预判与随后执行，且计划阶段不带工具定义。
