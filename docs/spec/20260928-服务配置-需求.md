# 服务配置：需求

## 目标与已确认范围

Web／桌面版「设置」新增「服务」菜单，集中管理应用**已支持**的外部服务配置。首个服务是 Serper 网络搜索，用户可在页面配置 `SERPER_API_KEY`，随后实际执行的 `web_search` 使用它。服务列表由应用代码显式定义；不允许用户自行添加任意服务、URL、Header 或配置字段。

## 已确认的迁移决定

- 搜索 Key 改由本机私有服务配置读取，**彻底停用 `.env`／进程环境回退**；旧 Key 由用户在页面手动输入，应用不自动导入。
- Web／桌面版提供设置界面；当前 TUI 工具白名单不包含 `web_search`，本次不顺带扩权。源码 Web 与 TUI 共用项目数据目录；独立桌面版使用自己的应用数据目录。

## 可观察行为与验收

1. 「服务」页列出代码已注册的服务及其字段；本版只有 Serper 的 API Key。页面可查看「已配置／未配置」、替换或删除，读取接口永不回显 Key，密码框保存后清空。
2. 保存或删除后，下一次真实 `web_search` 调用读取新配置，不需要重启；未配置时保持现有 `api_key_missing` 结果且不发网络请求。
3. 配置文件为本机私有明文文件，目录权限 `0700`、文件 `0600`；拒绝符号链接、权限过宽、超大或无效内容。多页面保存用修订号检测冲突，失败不破坏旧值。
4. 写入接口仅本机同源，严格限制请求大小、服务 ID 与字段。Key 不得进入 GET、浏览器持久化、日志、错误文案、仓库或测试真实凭据。
5. 服务配置结构支持未来由代码注册新的已知服务，而不要求每加一项就复制存储和 API；但本次不提供未接线服务的空配置。

## 技术与检查

- Python 3.11；通用服务注册和私有配置在 `app/runtime/`，搜索工具仍在 `tools/`，Web 接口与页面在 `app/webui/`。
- 使用假 Key、HTTPX MockTransport 测试存储、API、页面契约和 Web 搜索接线；不访问真实 Serper。
- `.venv/bin/python -m compileall -q main.py app tools tests`；`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q`；`.venv/bin/python -m pip check`；`git diff --check`。

## 边界

- 始终保留固定 Serper URL、查询／响应限额及只读自动执行规则；不把服务 Key 提供给模型。
- 不新增依赖、动态服务插件、任意网络端点、TUI 设置菜单或自动迁移脚本。
- 未经用户明确要求，不提交或推送；绝不提交真实密钥。
