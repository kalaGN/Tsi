## Phase 1：工具基础设施

### Task 1：建立根目录工具契约与 Registry

**说明：** 创建根目录 `tools/` Python 包，定义 Provider 中立的工具数据对象、Tool 协议和不可变白名单 Registry；先完成通用注册、参数解析、错误 envelope 与执行边界，不接入模型。

**验收标准：**

- [x] 工具名、描述、顶层 object Schema 和重名在注册时被确定性校验。
- [x] 非法 JSON、非 object 参数、未知工具和普通 Handler 异常转换为固定安全错误，不泄漏原始异常。
- [x] 多个调用严格串行，参数与结果按 UTF-8 字节执行 8/32 KiB 边界，取消不被吞掉。

**验证：**

```bash

PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q tests/test_tools.py
```

**依赖：** 无。

**文件：** `tools/__init__.py`、`tools/contracts.py`、`tools/registry.py`、`tests/test_tools.py`。

**规模：** M（4 个文件）。
