## 1. 实施原则

- 严格按依赖顺序推进，每个 Task 先补失败测试，再做最小实现。
- 每个 Checkpoint 都保持默认 HTTP、既有 TUI 对话和 `get_current_time` 可用。
- Workspace 测试只操作 `tmp_path`，不读取 `.env`、不修改当前真实仓库、不调用真实模型。
- 发现设计与源码冲突时先更新设计并重新确认，不静默改变安全语义。
- 不增加依赖，不提交 Git，除非用户在全部验收后明确要求。
