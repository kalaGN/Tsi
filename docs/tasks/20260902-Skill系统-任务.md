## 1. 实施原则

- 严格按依赖顺序执行；每项任务完成后先运行该任务验证，再进入下一项。
- 测试先行，所有 Skill、脚本、环境变量和 Provider 数据均使用临时目录与假值。
- 不调用真实模型、网络或用户现有 Skill 脚本。
- 脚本执行属于高风险边界；没有审批、脚本变化或生命周期回收失败时不得执行。
- 不改变 HTTP `/chat`、Session schema、Provider 协议和现有文件 Diff 审批语义。
- 代码和新增文档使用中文说明，代码标识、协议名与命令保留原文。
