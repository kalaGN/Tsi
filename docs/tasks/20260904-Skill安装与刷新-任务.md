## 1. 实施原则

- 严格按依赖顺序实施，每项先补失败测试，再写最小实现并运行定向验证。
- 所有安装测试使用 `tmp_path`、假 Home、假 GitHub 获取器和假 Provider，不访问真实网络和用户目录。
- 审批前不得读取 GitHub、Home 或写项目；审批与实际调用参数不一致时立即拒绝。
- 当前请求固定使用一个 Catalog、system prompt 和 Registry 快照；安装成功只影响下一次请求。
- 不修改 HTTP `/chat`、Session 文件格式、Provider 协议和现有 Skill 脚本审批语义。
- 不增加覆盖、升级、卸载、目录监控、依赖安装或私有 GitHub 凭据支持。
- 代码增加必要中文注释；文档使用中文；提交信息按项目规则使用中文。
