# TUI 单文件删除工具任务

## 概览

按已确认的[需求](../spec/20260909-TUI单文件删除工具-需求.md)和[设计](../plan/20260909-TUI单文件删除工具-设计.md)，测试先行扩展 Workspace 三态变更模型，再实现逐次审批的单文件删除工具，最后同步长期规则和使用文档。所有任务按依赖顺序串行执行，避免同时修改共享 Journal 和注册表。

## 架构决策

- 删除是现有 Workspace 写入闭环的一种状态，不创建第二套审批或撤销框架。
- `before/after` 三态表达创建、替换和删除；执行后摘要为 `None` 表示路径应不存在。
- `delete_workspace_file` 只加入 TUI Workspace 工厂和 `workspace_write` 意图组，HTTP 默认注册表保持只读。
- 每次删除必须经过哈希复验、完整有界 Diff 和本地审批，并可在当前进程中 LIFO 撤销。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 删除不可逆 | 高 | 当前进程 Journal 快照、LIFO 撤销、Git 兜底 |
| 审批后文件变化 | 高 | fingerprint、执行时重读和 SHA-256 复验 |
| 撤销覆盖用户新文件 | 高 | 结果状态为“不存在”并使用原子新建 |
| 三态模型影响已有编辑 | 中 | 保留创建/替换回归测试并在高风险任务后设检查点 |
| 工具列表增加 Token | 低 | 仅激活 `workspace_write` 后披露 |
